# Conversation Shell — 需求规格

## 概述

将 `byz` 的默认交互改为面向用户目标的自然对话壳：隐藏内部能力与执行细节，保留现有 Fast、Prewalk、workflow 能力但不在默认首屏主动暴露。

## 需求版本

| 日期 | 版本 | 说明 |
| --- | --- | --- |
| 2026-08-29 | v1 | 初始需求 |
| 2026-08-29 | v2 | 新增 runtime 展示与确认适配接口，确保对话壳可控制既有输出与确认体验 |

## 项目信息

- 项目名: pi-monorepo
- 架构类型: npm workspace monorepo；BYZ CLI 包装层
- 交付形态: 本地终端 CLI
- 设计基准: 结构级，`design-baseline/`

## 范围

**做：** 默认欢迎语、自然语言输入与结果呈现、低噪声进展、必要确认、按需详情、现有高级能力隐藏策略。

**不做：** 自动任务路由、本机长期记忆、项目治理、云同步、删除既有 Fast/Prewalk/workflow 实现。

## 用户故事

- 作为独立创作者，我想直接说明目标，以便不先学习命令、模型或工作流。
- 作为用户，我想在长任务中只获得必要进展，以便对话不被内部日志打断。
- 作为用户，我想在有影响的动作前理解影响并自然确认，以便保持控制。
- 作为高级用户，我想按需展开现有控制与技术详情，以便能力不丢失。

## 功能需求

1. [F-001] 无参数交互启动时，BYZ 必须以“你想让我帮你做什么？”作为默认首屏主提示。
2. [F-002] 默认会话输出不得主动显示模型、skill、workflow、工具调用、token 或内部步骤编号。
3. [F-003] BYZ 必须将普通完成、等待、需要决定、不可自动恢复和可选详情渲染为不同的业务语义状态；颜色只能辅助，不得是唯一表达。
4. [F-004] 长任务在 30 秒内没有可见结果时最多显示一次简短等待提示；正常执行不得连续刷出内部过程消息。
5. [F-005] 需要确认的动作必须显示影响、推荐选择、替代选择与拒绝后的状态，并接受自然语言确认；现有快捷键可以作为可选别名。
6. [F-006] Fast、Prewalk、workflow 的现有功能必须继续可用，但默认欢迎、普通结果和帮助摘要不得主动宣传它们；用户请求高级控制或详情时才展示相关入口。
7. [F-007] bundled runtime 必须提供受控的展示与确认适配接口，使 BYZ 能在不改变底层权限、工具或模型执行语义的前提下，分类、过滤和渲染用户可见输出及确认选项。

## 非功能需求

- 兼容性: 现有 `byz` 非交互参数、`byz update`、workflow 管理命令与现有 slash command 行为保持可用。
- 可访问性: 颜色状态必须有明确文字；窄终端不得截断当前待决动作。
- 性能: 输出层不得引入额外模型调用或网络请求。
- 安全: 不得在默认输出或状态摘要中暴露凭据、token、Cookie、模型请求内容或文件绝对路径。

## 验收标准

- [ ] [AC-001] 在 TTY 无参数启动时，首个主提示为“你想让我帮你做什么？”，且不显示模型、workflow 或 Fast 信息。
- [ ] [AC-002] 普通任务完成输出只含自然回应、核心结果和可选下一步；不含内部工具或步骤文本。
- [ ] [AC-003] 等待、待决、不可恢复失败和完成状态都有文字状态，并分别符合结构基准的语义层级。
- [ ] [AC-004] 长任务只显示一次等待提示；同一执行期间后续内部事件不重复生成等待行。
- [ ] [AC-005] 确认提示明确说明影响、推荐、替代项和取消/拒绝结果；用户可输入自然语言选择或原有快捷选择。
- [ ] [AC-006] 用户请求“展开细节”后才显示高级控制或技术详情；未请求时 Fast、Prewalk、workflow 不出现在普通输出。
- [ ] [AC-007] `byz update`、`byz workflow list`、`--fast`、`/fast`、`/prewalk` 和 `/workflow` 的现有行为回归通过。
- [ ] [AC-008] 80 列终端中，待决提示与至少一个自然语言选项完整可读。
- [ ] [AC-009] runtime 展示适配器能让 BYZ 对普通结果、进展、失败、详情和待决提示应用展示策略；适配器不得改变底层工具调用、权限或确认的真实执行结果。

## 依赖

- `packages/byz/src/cli.js` 的现有 runtime 启动与扩展注册。
- bundled runtime 的交互 UI/extension API。
- 结构基准：`design-baseline/byz-terminal-scenarios.html`。

## 开放问题

- 无。本 feature 仅实现 M1；自动路由、长期记忆和项目治理由后续 feature 定义。
