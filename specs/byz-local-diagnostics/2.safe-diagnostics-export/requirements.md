# Safe Diagnostics Export — 需求规格

## 概述

允许用户在本地预览并主动生成经过隐私检查的诊断包，不自动上传，不允许授权绕过禁止字段。

## 项目信息

- 项目名: pi-monorepo
- 架构类型: Node.js npm workspace monorepo；BYZ CLI 产品层
- 交付形态: CLI
- 上下文范围: full

## 用户故事

- 作为 BYZ 用户，我希望在导出前看到诊断包的时间范围和字段类别，以便确认将要分享什么。
- 作为 BYZ 用户，我希望生成只包含脱敏摘要的本地诊断包，以便主动提交给开发者分析。
- 作为 BYZ 维护者，我希望导出器对禁止字段采取失败关闭策略，以便损坏或未知日志不会造成隐私泄露。

## 功能需求

1. [F-001] BYZ 必须提供 `byz diagnostics export`，默认导出本地聚合摘要、清单、Schema 版本、产品/运行时版本和隐私检查报告，不默认包含原始事件。
2. [F-002] 导出前必须显示时间范围、事件数量、字段类别、输出路径和将被排除的数据类别，并要求用户明确确认；非交互环境缺少确认参数时必须拒绝导出。
3. [F-003] 导出器必须重新按白名单验证所有待导出字段，不得信任事件文件已在写入时验证；出现未知字段、自由文本、损坏结构或禁止字段时必须拒绝导出。
4. [F-004] 诊断包禁止包含 Prompt、模型回复、会话正文、文件/代码/Diff、工具参数或输出、用户名、项目名、绝对路径、URL、凭证、Header、原始 Provider 请求响应和自由文本错误消息。
5. [F-005] 导出必须只生成本地文件，不得上传、创建 Issue、打开浏览器或发起网络请求。
6. [F-006] 用户指定输出路径时，导出器必须拒绝符号链接逃逸、拒绝覆盖现有文件，且不得把临时文件留在目标目录之外。
7. [F-007] 导出失败或取消时必须清理本次创建的临时产物；清理失败时返回非零并列出不含敏感路径内容的相对产物名。
8. [F-008] 导出命令可以执行显式的磁盘读取和聚合，但不得与正在运行的 BYZ 主流程共享阻塞锁；运行期记录继续允许丢弃并优先服务主流程。
9. [F-009] AI 只有在用户明确指定诊断包或摘要后才能读取；生成诊断包本身不构成上传或自动分析授权。

## 非功能需求

- 安全: 导出阶段二次白名单校验，失败关闭；输出文件使用用户私有权限。
- 可靠性: 原子完成最终文件；失败时不留下看似成功的半成品。
- 隐私: 默认只导出聚合摘要，不导出原始事件。
- 兼容性: 支持 Node.js `>=22.19.0`；交互与非交互确认行为明确。

## 验收标准

- [ ] [AC-001] `diagnostics export` 在确认前显示时间范围、事件数量、字段类别、排除类别和输出路径，取消后不生成文件。
- [ ] [AC-002] 默认诊断包只包含 manifest、聚合 summary 和 privacy report，不包含原始 JSONL 分片。
- [ ] [AC-003] 注入任一未知字段、绝对路径、Prompt、工具参数、工具输出、URL、Token 形态字段或自由文本错误消息后，导出返回非零且不生成最终包。
- [ ] [AC-004] 损坏 JSON、未知 Schema 版本或不完整必需字段导致导出失败关闭，不被静默忽略为安全数据。
- [ ] [AC-005] 非交互环境未提供明确确认时拒绝导出；提供确认后行为与交互确认一致。
- [ ] [AC-006] 输出目标已存在、是符号链接或解析到不允许位置时拒绝覆盖，现有文件内容不变。
- [ ] [AC-007] 导出成功后最终文件仅当前用户可读，manifest 记录诊断 Schema 版本和生成工具版本，不记录用户名、项目名或绝对路径。
- [ ] [AC-008] 导出成功、失败和取消路径均不发起网络请求，不自动创建 Issue 或启动浏览器。
- [ ] [AC-009] 模拟写入失败时不产生可被误认成成功包的最终文件；临时产物清理失败会返回非零。
- [ ] [AC-010] 导出期间并发运行的 BYZ 不等待导出锁；运行期记录结果和退出行为与无导出进程时一致。
- [ ] [AC-011] 生成诊断包后，BYZ 不自动把其内容加入 AI 上下文；只有用户明确指定后才允许读取摘要。

## 依赖

- `1.local-diagnostics-foundation` 的 Schema、受管目录、摘要读取器和隐私验证器。
- BYZ CLI 命令路由和 Node.js 文件系统能力。

## 开放问题

- 无。MVP 导出格式采用本地目录包或单一归档格式由技术设计决定，但必须满足原子完成、用户私有权限和不新增第三方运行时依赖的约束。
